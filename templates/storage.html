Automatic Cleanup Lifecycle:

1. Nightly Background Daemon: A dedicated thread verifies timestamps every 24 hours against the configured RETENTION_DAYS threshold.

2. Synchronized Deletion: When an event exceeds the retention threshold, its snapshot JPG file is purged from disk, empty date folders are pruned, and corresponding SQLite rows in both events and notifications are removed in a single atomic database transaction.

3. Manual Cleanup: Administrators can trigger an immediate retention sweep at any time using the "Run Retention Cleanup Now" button above.
